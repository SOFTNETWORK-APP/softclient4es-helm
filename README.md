# softclient4es-helm

Helm charts for the [SoftClient4ES](https://softclient4es.dev/) ecosystem.

## Charts

- [`softclient4es-federation/`](softclient4es-federation/) — deploys the SoftClient4ES
  multi-cluster federation Arrow Flight SQL server plus optional per-Elasticsearch-version
  sidecars.

See each chart's own `README.md` for installation and configuration details.
